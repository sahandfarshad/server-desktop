# Server Desktop

پنل تحت وب برای نصب یک دسکتاپ خیلی سبک لینوکس (IceWM) روی سرورها، با دسترسی از طریق Remote Desktop (xrdp).
روی سرور اصلی نصب می‌شود و از داخل پنل، با رمز SSH، روی سرورهای دیگر دسکتاپ نصب می‌کند.

## نصب روی سرور اصلی

```bash
bash <(curl -fsSL https://github.com/sahandfarshad/server-desktop/releases/latest/download/install.sh)
```

بعد از نصب، منو با دستور `sd` باز می‌شود و آدرس پنل بالای منو است.

## افزودن سرور

در پنل: IP، پورت و رمز SSH، نام کاربری و رمز دسکتاپ، پورت Remote Desktop (پیش‌فرض 3389)، و اختیاری: نصب Firefox و دسترسی sudo.
بعد از نصب، از پنل فایل `.rdp` را دانلود کن یا آدرس `IP:پورت` را در Remote Desktop Connection ویندوز (mstsc)، Microsoft Remote Desktop / Windows App در مک و موبایل، یا Remmina در لینوکس بزن.

چیزهایی که نصب می‌شود: IceWM (با تسک‌بار)، xrdp + xorgxrdp، ترمینال xterm، فایل‌منیجر PCManFM، فونت‌های فارسی (Vazirmatn و Noto) و در صورت انتخاب Firefox از مخزن رسمی Mozilla.

سرور مقصد: Ubuntu 22.04 / 24.04 یا Debian 12 / 13، پورت RDP در فایروال دیتاسنتر باز. حدود ۱۵۰ مگابایت رم برای هر جلسه‌ی دسکتاپ.

## امنیت

- رمزهای SSH و دسکتاپ روی سرور اصلی با AES-GCM رمزنگاری می‌شوند.
- اثر کلید SSH هر سرور در اولین اتصال ذخیره و بعد بررسی می‌شود.
- رمزها از طریق stdin به سرور مقصد می‌روند؛ روی آن فقط به شکل رمز کاربر لینوکس ذخیره می‌شوند.
- ورود root از RDP بسته است؛ برای کاربر دسکتاپ یک رمز قوی بگذار و در صورت امکان پورت را از 3389 عوض کن.
